# Academic Evidence Extraction

1. Read `manifests/source_manifest.json` and select an explicitly registered source.
2. Record citation metadata and page spans before summarizing evidence.
3. Keep each summary concise and limited to what the cited pages support.
4. Append structured rows to the case-local evidence ledger.
5. Report missing evidence instead of filling gaps with unsupported claims.
6. Keep private paths, full copyrighted text, and personal annotations outside shared outputs.
