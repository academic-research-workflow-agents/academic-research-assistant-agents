# 能力与边界

## 可以协助的事项

- 从用户提供的学术来源中提取证据并记录页码、引用键和置信度；
- 清理、拼接数据并保留输入、步骤、输出和运行元数据；
- 执行 Stata 任务，交付设定、数值、表图和诊断；
- 将 manifest 登记的用户原文转换为 Markdown 或 LaTeX 排版；
- 将已有材料压缩为有来源的 Beamer slides；
- 协调所需能力并报告阻塞项；
- 检查路径、契约、来源追踪、编译结果和能力边界。

## 不提供的事项

- 不凭主题补充研究观点、发现、解释或结论；
- 不把技术结果包装成可直接提交的学术正文；
- 不改变用户原文措辞；
- 不在来源不完整时继续制作 slides；
- 不把 synthetic 示例描述成真实研究结果。

## 证据约束

每个公开 presentation frame 必须只有一个 `\label{slide:<id>}`。对应 manifest 中的 slide 必须列出至少一个有效 `source_ref`，并声明允许的变换类型。任何一项缺失都会使检查失败。
