# Synthetic 静态记录

这些 JSON 文件只展示 public 契约的最小形态，不执行 private 工作流，也不对应任何真实研究项目。

- `evidence_card.json`：来源、页码、摘录和置信度；
- `data_asset_manifest.json`：数据输入、处理步骤和输出哈希；
- `regression_result.json`：模型设定、数值和诊断；
- `formatting_provenance.json`：用户源文件、哈希和机械转换；
- `research_coordination_manifest.json`：请求能力、状态和阻塞项；
- `research_check_report.json`：契约、来源和边界检查结果。
