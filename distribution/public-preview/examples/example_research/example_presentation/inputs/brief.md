# Evidence-bound Academic Research Assistance

Subtitle: Synthetic public preview for version 0.2.0.

The private product contains seven research support capabilities: evidence records, data assets, Stata technical results, user-source LaTeX layout, source-bound Beamer presentations, capability coordination, and validation checks.

Every visible slide must reference registered user material or an evidence asset.

Allowed presentation transformations are verbatim, extract, compress, and layout.

Missing sources, unknown source references, or unregistered frames must stop the presentation workflow.

The public preview exposes only this minimal demonstration and synthetic contract records.
