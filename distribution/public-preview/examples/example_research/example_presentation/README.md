# Evidence-bound Presentation Demo

This public-only fixture demonstrates a small source-to-slide chain:

- `inputs/brief.md` is the sole source;
- `manifests/presentation_manifest.json` registers every slide;
- `source/main.tex` gives every frame one `slide:<id>` label;
- `templates/public-minimal/` is deliberately small and is not a private template.

Run the commands from the public preview repository root.
