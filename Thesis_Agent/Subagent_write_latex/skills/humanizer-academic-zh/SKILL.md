# 学术 Humanizer（中文）

本技能用于改写中文学术论文文本，目标是去除明显的 AI 味、套话味和空泛拔高，同时保留学术写作所需的定义精度、证据边界和实证结构。

按需读取：
- `references/section-playbook.md`：分论文章节的改写指引
- `references/anti-patterns.md`：需要优先清理的学术 AI 套话

## 工作流

1. 先判断当前文本属于哪一类章节，并保留该章节的功能；如果是摘要、引言、关键词或结论，使用 `section-playbook` 中的前置章节补充规则叠加到原模板规则上，而不是替代原规则。
2. 删除空泛拔高、模糊归因、模板化贡献表述和泛化政策语言。
3. 保留变量名、模型设定、样本期、系数方向、数量级、表格引用和因果边界。
4. 追求准确、克制、清楚的学术表达，而不是口语化的“更像真人说话”。
5. 默认只输出改写后的文本；仅当用户要求时再补简短说明。

## 硬规则

- 不编造数据、变量、系数、文献、样本期、机制、政策建议或研究贡献。
- 不擅自套学校、学院、期刊格式。
- 不把论文文字改成营销文、博客文或聊天回复。
- 不为了“去 AI 味”而削弱定义、识别逻辑或计量细节。
- 保留必要的审慎措辞，但删除堆叠式限定和无信息量软化表达。
- 保留方程编号、表格编号、变量缩写和学科术语。

## 公式环境规则

- 单行且需要编号的公式，用 `equation`。
- 多行但只需要一个总编号的公式，用 `equation` + `aligned`。
- 多行且需要逐行编号的公式，用 `align`。
- 只有在用户明确不想编号时，才继续使用 `\[...\]`、`equation*` 或 `align*`。
- 所有需要在正文引用的公式，都必须补 `\label{eq:...}`，并在正文中用 `\eqref{eq:...}` 引用。
- 纯符号级、嵌句内的数学表达继续保留为 `\(...\)`，不要硬改成独立编号公式。
- 定义式、主回归式、机制方程和识别方程默认视为应编号对象，除非用户明确要求不编号。

## 路由

- 摘要、引言、关键词、文献综述、机制与假设：读 `references/section-playbook.md`
- 变量说明、数据来源、模型设计、回归解释、稳健性检验、结论与启示：读 `references/section-playbook.md`
- 如果文本明显存在空话、套话、拔高或模板味：读 `references/anti-patterns.md`

## 输出

默认输出：
- 改写后的文本

按需附加：
- 简短说明主要删改点
