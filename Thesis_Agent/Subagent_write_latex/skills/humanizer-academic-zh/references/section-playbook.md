# 章节改写指引

只读取与当前任务对应的小节。
其中前置章节的补充规则用于叠加到原有模板要求上，不替代摘要、引言、结论等章节的原始功能。

## 摘要

目标：
- 交代研究问题、样本或数据、方法、主要结果和有限度贡献。

改写重点：
- 删除铺垫式重要性宣告和宏大背景。
- 保留样本期、研究对象、识别策略和核心结论。
- 如证据边界有限，保留必要审慎措辞。
- 补充顺序优先按“研究对象或问题 -> 样本与识别 -> 主结果 -> 必要时补一层机制或异质性 -> 有限启示”推进。
- 首句允许有 1 句短背景，但第二句前必须落到“本文研究什么”。
- 不把“丰富文献”“具有重要现实意义”这类贡献套话塞回摘要结尾。

## 引言

目标：
- 说明研究问题、研究缺口和本文贡献。

改写重点：
- 尽快从背景过渡到具体研究问题。
- 贡献写具体，不写口号。
- 不把引言写成政策宣传或时代叙事。
- 补充顺序优先按“短背景 -> 研究问题 -> 文献缺口 -> 设计预告 -> 贡献”推进。
- 背景控制在 1-2 句内，避免几段宏观叙事之后仍看不到问题、设计和贡献。
- 方法论文那种“方法张力先行”的开篇方式可以借鉴结构感，但不要直接覆盖 thesis 实证引言的写法。

## 文献综述

目标：
- 梳理研究脉络、争议点、机制分歧或本文切入点。

改写重点：
- 强调归纳与比较，而不是作者名单堆砌。
- 避免“已有研究普遍认为”这类无支撑总结。
- 保留争议和未解决问题。

## 机制与假设

目标：
- 先解释机制，再提出可检验假设。

改写重点：
- 先界定机制，再落到方向性判断。
- 直写假设逻辑，不做修辞性铺垫。
- 避免假设前的大段宏观口号。

## 变量说明、样本与模型

目标：
- 清楚定义变量、样本、数据来源与模型设定。

改写重点：
- 把“对象是什么”放在前面，再写构造、来源、处理方式和识别含义。
- 保留变量缩写、模型符号、滞后项、固定效应、聚类标准误、缩尾等技术细节。
- 用操作性语言替代抽象表述。

## 回归结果解释

目标：
- 准确说明方向、显著性、数量级和经济含义。

改写重点：
- 按“结果 -> 数量级 -> 机制或假设 -> 有限解释”的顺序推进。
- 保留列号、表号、基准回归等信息。
- 避免“充分证明”“完全说明”之类过强表述。

## 稳健性检验

目标：
- 说明替换了什么、结果如何变化、结论是否保持。

改写重点：
- 先点明检验方式，再写符号、显著性、幅度是否变化。
- 区分“稳健”“减弱”“混合”三种情况。
- 不夸大稳健性。

## 结论与启示

目标：
- 概括主要发现，并给出有限度启示。

改写重点：
- 启示必须紧扣结果。
- 避免“意义重大”“前景光明”式空话。
- 用收束性的结论替代口号式结尾。
- 补充顺序优先按“主结果 -> 关键机制或扩展结果 -> 有限启示或边界”推进。
- 如果正文已经做过机制和异质性，结论只回收最关键的一层，不重述整套表格。
- 若要写局限，目的是澄清边界，而不是改写成 future research 愿望清单。

## 关键词

目标：
- 用最少的词稳定覆盖主题词、研究对象或场景词，以及必要时才出现的方法词。

改写重点：
- 只改写作者已经显式给出的关键词，不根据主题自行补词。
- 中文关键词一般保留 `3-5` 个，优先 `4` 个；主题词在前，对象或场景词居中，方法词放后且最多 1 个。
- 使用稳定分隔方式；中文优先 `；`，不要中英文混写或把关键词写成完整短句。
