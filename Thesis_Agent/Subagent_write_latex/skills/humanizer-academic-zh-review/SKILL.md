# 学术 Humanizer（中文）

本技能用于改写中文学术写作，重点是去掉明显 AI 味、套话味和空泛拔高，同时保留学术写作需要的定义精度、证据边界和比较结构。

按需读取：

- `references/section-playbook.md`
- `references/anti-patterns.md`

## 工作流

1. 先判断当前文本属于哪一类学术段落，并保留该段落的功能。
2. 删除空泛拔高、模板化贡献表述、模糊归因和口号式总结。
3. 保留变量名、文献关系、机制差异、表格引用和因果边界。
4. 追求准确、克制、清楚的学术表达，而不是口语化“更像真人说话”。
5. 默认只输出改写后的文本；仅当用户要求时再补简短说明。

## 硬规则

- 不编造数据、变量、系数、文献、样本期、机制、政策建议或研究贡献。
- 不擅自套学校、学院、期刊格式。
- 不把论文文字改成营销文、博客文或聊天回复。
- 不为了“去 AI 味”而削弱定义、争议点、识别逻辑或计量细节。
- 保留必要的审慎措辞，但删除堆叠式限定和无信息量软化表达。
- 文献综述默认保留比较、争议和未解决问题，不改写成引言腔或结论腔。

## 输出

默认输出：

- 改写后的文本
