# 章节改写指引

只读取与当前任务对应的小节。

## 文献综述

目标：

- 梳理研究脉络、比较分歧、保留争议、识别研究空白。

改写重点：

- 强调归纳、比较与争议，而不是作者名单堆砌。
- 避免“已有研究普遍认为”这类无支撑总结。
- 不把综述写成引言：不要写 `本文贡献`、`本文结构`、问题提出式自我导入。
- 不把综述写成结论：不要写政策启示、未来研究或总结性收束。

## 机制与假设

目标：

- 先解释机制，再提出方向性判断或可检验命题。

改写重点：

- 先界定机制，再落到方向性判断。
- 避免修辞性铺垫和宏观口号。

## 变量说明、样本与模型

目标：

- 清楚定义变量、样本、数据来源与模型设定。

改写重点：

- 先写对象是什么，再写构造、来源、处理方式和识别含义。
- 保留变量缩写、模型符号、固定效应、聚类标准误等技术细节。

## 回归结果解释

目标：

- 准确说明方向、显著性、数量级和经济含义。

改写重点：

- 按“结果 -> 数量级 -> 解释”的顺序推进。
- 避免“充分证明”“完全说明”之类过强表述。

## 稳健性检验

目标：

- 说明替换了什么、结果如何变化、结论是否保持。

改写重点：

- 区分“稳健”“减弱”“混合”三种情况。
- 不夸大稳健性。
