# 章节改写指引

只读取与当前任务对应的小节。
其中前置章节补充层用于叠加到原有经金实证模板和作者风格规则上，不替代原章节功能。

## 摘要

目标：
- 交代研究问题、样本或数据、方法、主要结果和有限度贡献。

改写重点：
- 删掉重要性铺垫和口号化背景。
- 保留样本期、研究对象、识别策略和核心发现。
- 用克制的方式处理贡献和启示。
- 补充顺序优先按“研究对象或问题 -> 数据与识别 -> 主结果 -> 必要时补一层机制或异质性 -> 有限启示”推进。
- 中文摘要首句可以有 1 句短背景，但第二句前必须落到“本文研究什么”。
- 若后续要写英文摘要，默认跟随已确认中文摘要的结构锚点，而不是反向牵引中文摘要。

## 引言

目标：
- 说明研究问题、研究缺口和本文切入点。

改写重点：
- 尽快进入具体问题。
- 用更实的语言写贡献，不写泛化的理论意义或现实意义。
- 保留制度背景和研究动机，但不要过度铺陈。
- 补充顺序优先按“现实或制度背景 1-2 句 -> 研究问题 -> 文献缺口 -> 设计预告 -> 贡献”推进。
- 引言前部不提前塞入完整文献综述主体，问题、设计和贡献要比大背景更早露面。
- 方法论文的开篇张力只可借其压缩感，不直接照搬为 thesis 实证引言。

## 文献综述

目标：
- 梳理研究分支、争议点、识别差异或本文的补充位置。

改写重点：
- 强调比较、承接和分歧。
- 避免作者名单式堆砌和无支撑的“普遍认为”。
- 保留经金论文常见的“已有研究关注 A/B/C，但对 D 讨论较少”结构。

## 机制与假设

目标：
- 先解释机制，再提出可检验假设。

改写重点：
- 明确作用渠道、边界条件和方向性预测。
- 保留实证论文常见的“基于上述分析，提出假设”的推进感，但不写成模板。
- 不做情绪化或口号式铺垫。

## 变量说明、样本与模型

目标：
- 清楚定义变量、样本、数据来源与模型设定。

改写重点：
- 按“先界定对象，再说明实际使用的数据来源，再解释构造或必要处理，最后交代这样设定的含义”的顺序写。
- 如果用户已经手改过当前段落，默认保留段落顺序和句子骨架，只 patch 未写实的事实点。
- 用户只否定某个细节时，只 patch 那个细节，不要顺手改写整句或整段。
- 只写进入当前变量或样本构造的内容，不把未使用的数据层、备用口径或验证性材料塞进正文。
- 把技术处理改写成论文语言，不直接写脚本名、文件名、输出路径或流水线顺序。
- 变量解释优先正面界定“它衡量什么”，不要靠“而不是……”来下定义。
- 正文只保留简洁、可读的构造逻辑；数据库附录规则、关键词表、代码清单和特殊处理放补充说明。
- 项目内简称第一次出现在正文时，要当场交代来源和所指对象，不能只给一个简称再把解释推给附录。
- 有现成正式类别名时，优先用正式类别名和精确数字做概括，不要自造模糊总称。
- 在 direct_latex 模式下，较长的补充说明默认移入附录，不要继续挂在正文小节里。正文里直接写“详见附录A/附录B/附录C”，而不是把长说明塞成脚注。
- 如果同一节下面的小标题过密、每段内容偏短，优先收并为自然段，不要把正文写成提纲或说明书。
- 自构数据不要写得像公开现成数据。要点明是项目整理口径，但只写当前已核验的构造结果。
- 数据库内部表名、字段名和脚本侧标识默认不进正文；只有在用户明确需要或正文确实离不开时，才放进补充说明。
- 普通数字、年份、样本量、阈值和代码值默认不用 `\texttt{}`；`\texttt{}` 留给变量名、字段名、文件名等标识符。公式里若含数字，优先改用数学模式，不要把数字包进等宽体。
- 中文正文里，阿拉伯数字与中文单位、量词或叙述成分之间默认不留空格，如“100万美元”“342个城市单元”“2000--2024年”。不要把英文排版习惯带进中文句子。
- 发现“特定规则”“标准城市”“拥有”等模糊词时，优先改成精确口径；若正文不宜展开，就移动到补充说明。
- 少写解释性句尾，例如“这些字段足以……”“这一选择保证了……”；除非用户明确要解释理由，否则事实写到位就停。
- 中文优先追求顺和可读，不机械追求主谓宾对称；只要前后能自然衔接，就不要为了“完整”把句子写硬。
- 保留变量缩写、模型符号、滞后项、固定效应、聚类标准误、缩尾等技术细节。
- 用更紧凑的语言表达操作步骤和识别含义。

## 回归结果解释

目标：
- 准确说明方向、显著性、数量级和经济含义。

改写重点：
- 按“结果 -> 数量级 -> 机制/假设 -> 有限解释”的顺序推进。
- 当源文本给出相对样本均值或经济量级时，优先保留。
- 保留“与假设一致”“说明可能存在某种机制”这类实证论文解释逻辑，但避免重复句式。

## 稳健性检验

目标：
- 说明替换了什么、结果如何变化、结论是否保持。

改写重点：
- 先点明检验方式，再写核心结果。
- 分清“符号不变”“显著性略降”“整体稳健”等层次。
- 不夸大稳健性结论。

## 结论与启示

目标：
- 概括主要发现，并给出有限度启示。

改写重点：
- 保留经金实证论文的收束结构，但压缩口号式政策拔高。
- 先总结结论，再给有限度政策或研究含义。
- 结尾以结果约束启示，而不是用大词收尾。
- 补充顺序优先按“主结果 -> 关键机制或扩展结果 -> 有限启示或边界”推进。
- 若正文已经完成机制与异质性，结论里只回收最关键的一层，不按表格顺序机械重述。
- 若要写局限，目的是交代边界，而不是另起 future research 清单。

## 关键词

目标：
- 用尽量少且稳定的关键词覆盖主题词、对象或场景词，以及必要时才出现的方法词。

改写重点：
- 只改写作者已显式给出的关键词，不根据论文主题自行补词。
- 中文关键词建议保留 `3-5` 个，优先 `4` 个；主题词在前，对象或场景词在中，方法词至多 1 个且放在后面。
- 分隔符保持稳定；中文优先 `；`，不要把关键词写成完整短句、口号或中英文混排列表。
