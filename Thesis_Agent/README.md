# Thesis_Agent

This is a shareable thesis-workflow agent framework for sharing or reuse.

It includes:

- root routing rules
- subagent contracts
- generic scripts and schemas
- synthetic examples

It does not include private papers, real data, generated outputs, logs, archived runs, or institution-specific templates.

## Example Layout

```text
Subagent_check/examples/example_thesis/example_case/
Subagent_integrate/examples/example_thesis/example_case/
Subagent_process_data/examples/example_thesis/example_case/
Subagent_read_paper/examples/example_thesis/example_case/
Subagent_regress_stata/examples/example_thesis/example_case/
Subagent_write_latex/examples/example_thesis/example_case/
```

Use these examples as structure references only. Add real materials in a private workspace, not in this shared package.
