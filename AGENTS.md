# Academic Research Workflow Agents

## Role
This repository is a private umbrella monorepo for reusable academic research workflow agent frameworks.

Default user-facing language: Chinese.

## Subprojects
- `Thesis_Agent/`: reading, data preparation, regression, writing, integration, and thesis checks.
- `Slides_Agent_Tex/`: TeX/Beamer slide authoring, template adaptation, deck assembly, integration, and checks.

## Privacy Contract
Keep the repository framework-only. Do not commit personal data, private project names, copyrighted full-text papers, real datasets, generated PDFs, logs, archived runs, local absolute paths, API keys, or institution-specific templates.

Real work should live in private working directories and should use these frameworks as reusable structure, scripts, skills, and examples.

## Routing
When working inside a subproject, read that subproject's `AGENTS.md` first and follow its local routing rules.
