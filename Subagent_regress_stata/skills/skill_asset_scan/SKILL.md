# skill_asset_scan

Use this skill to:
- scan `data/`
- read `data/data_sources.json`
- summarize direct files, folders, junctions, and manifest entries
- infer id, time, cluster, fixed-effect, and numeric candidates

This skill is reusable. It does not own the user-facing regression workflow.
